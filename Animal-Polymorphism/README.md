# Animal Polymorphism

Учебный проект на C#. Демонстрирует принципы ООП на примере животных.

## Что используется
- Абстрактный класс `Animal` с методами `Speak()` и `Move()`
- Наследование: классы `Lion`, `Eagle`, `Fish`
- Полиморфизм: массив `Animal[]`, вызов методов без привязки к конкретному типу
- Паттерн `is` для проверки типа (`Eagle` имеет дополнительное свойство `WingSpan`)
- Инкапсуляция: валидация возраста через свойство `Age`

## Как запустить
1. Склонировать репозиторий
2. Открыть в Visual Studio / VS Code
3. `dotnet run`
